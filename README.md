# Монитор Avito → Telegram

GitHub Actions раз в 30 минут открывает поиск Avito, проверяет новые объявления,
отсеивает цену выше 35 000 ₽ и нежелательные фразы, затем отправляет подходящие
варианты в Telegram. Уже просмотренные ссылки хранятся в кэше GitHub Actions.

## 1. Подготовьте правильную ссылку Avito

Откройте Avito вручную и выставьте:

- Энгельс, радиус 50 км;
- автомобили;
- цена от 0 до 35 000 ₽;
- остальные нужные фильтры.

Нажмите «Показать объявления» и скопируйте полный URL из адресной строки.
Исходная ссылка из переписки содержит внутренний фильтр **до 30 000 ₽**, поэтому
для диапазона до 35 000 ₽ обязательно получите новую ссылку через интерфейс Avito.

## 2. Создайте репозиторий GitHub

1. На github.com нажмите **New repository**.
2. Для полностью бесплатных Actions выберите **Public**. Код не содержит токен,
   но URL поиска будет храниться в Secret. Можно выбрать Private: на GitHub Free
   имеется 2 000 минут Actions в месяц.
3. Загрузите в корень репозитория все файлы из этой папки, включая `.github`.

## 3. Добавьте секреты

В репозитории откройте:

**Settings → Secrets and variables → Actions → New repository secret**

Создайте три секрета:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | `2017452773` |
| `SEARCH_URL` | новая полная ссылка Avito с ценой до 35 000 ₽ |

Токен нельзя добавлять непосредственно в код или файл `.env` в репозитории.

## 4. Первый запуск

1. Откройте вкладку **Actions**.
2. Выберите **Avito monitor**.
3. Нажмите **Run workflow**.
4. Откройте запущенную задачу и проверьте журнал.

После успешной проверки workflow будет запускаться приблизительно в 07 и 37 минут
каждого часа. GitHub может задерживать запланированные задачи при высокой нагрузке.

## Фильтрация

По умолчанию исключаются фразы: «без документов», «нет документов», «битая»,
«битый», «после ДТП», «на запчасти», «под разбор», «утиль», «не на ходу» и
«требует восстановления». Они ищутся в заголовке, цене и полном описании без
учёта регистра.

Для собственного списка добавьте repository secret `BANNED_PHRASES`, перечислив
фразы через `|`, а в шаг `env` файла `.github/workflows/monitor.yml` добавьте:

```yaml
BANNED_PHRASES: ${{ secrets.BANNED_PHRASES }}
```

## Важные ограничения

- Avito может показать CAPTCHA или ограничить IP GitHub. Скрипт не обходит защиту.
- Если запуск завершился ошибкой, внизу страницы запуска может появиться артефакт
  `avito-debug-*` со снимком страницы.
- Верстка Avito периодически меняется; тогда селекторы в `monitor.py` потребуется
  обновить.
- Полное описание длиннее лимита Telegram отправляется несколькими сообщениями.
- Публичные scheduled workflows GitHub может отключить после 60 дней отсутствия
  активности в репозитории; ручной запуск или коммит снова активирует workflow.

## Локальная проверка (необязательно)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install chromium
$env:TELEGRAM_BOT_TOKEN="..."
$env:TELEGRAM_CHAT_ID="2017452773"
$env:SEARCH_URL="полная ссылка Avito"
python monitor.py
```
